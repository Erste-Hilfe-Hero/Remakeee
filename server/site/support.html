Häufige Fragen

Warum braucht Chimora Internet?
Dein Spielstand liegt auf unserem Server in Deutschland. So geht er nicht verloren, wenn dein Handy kaputt geht, und du kannst mit Freunden Grüße, Geschenke und Duelle austauschen. Bricht die Verbindung ab, pausiert das Spiel und macht von selbst weiter, sobald sie wieder da ist.

Wie nehme ich meinen Spielstand auf ein neues Handy mit?
Auf dem alten Gerät Menü → Konto → Code für neues Handy. Auf dem neuen Gerät Code eingeben... wählen. Der Code gilt 7 Tage. Eine E-Mail-Adresse brauchst du dafür nicht.

Ich habe einen Fehler gefunden.
Schreib uns, was passiert ist, welches Gerät du nutzt und deinen Freundescode (steht oben im Menü Konto). Ein Screenshot hilft.

Jemand nutzt einen unpassenden Namen.
Beim Freund Melden antippen. Wir prüfen Meldungen jede Woche, das Ergebnis steht unter Konto, Nachrichten vom Team. Ohne Spiel geht es über das Formular Inhalt melden.

Kostet das Spiel etwas?
Nein, Chimora ist kostenlos. Es gibt keine Werbung und keine Lootboxen. Im Shop gibt es optionale Käufe, manche davon mit Vorteilen im Spiel. Alles zu Rissglas, Pass, Erstattung und Ausgabelimits steht unter Hilfe zu Käufen.

Chimora: help and contact

Email: aa.amuri@icloud.com (we usually answer within 2 working days)

Why does Chimora need the internet? Your save lives on our server in Germany, so it is safe if your phone breaks, and you can swap greetings, gifts and duels with friends. If the connection drops, the game pauses and carries on by itself once it is back.

How do I move my save to a new phone? On the old phone tap Menu → Account → Get a transfer code, on the new one Enter a code.... The code is valid for 7 days. No email needed.

I found a bug. Tell us what happened, your device and your friend code (Menu → Account). A screenshot helps.

Does the game cost anything? No, Chimora is free. No ads and no loot boxes. The shop has optional purchases, some with advantages in the game. Riftglass, the pass, refunds and spending limits are explained under Help with purchases.
