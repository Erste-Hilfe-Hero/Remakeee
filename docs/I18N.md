# Languages

Chimora ships in 14 languages: English, German, French, Spanish, Italian, Portuguese (Brazil), Dutch, Polish, Turkish, Russian, Japanese, Korean, Simplified Chinese and Traditional Chinese (the nine languages of the genre's current console games plus five more). The player picks the language from a list under Settings, then Display and access, where every language is shown in its own words. The first start uses the device language if the game has it (Chinese picks the script from the region, any Portuguese gets Brazilian Portuguese).

## How it works

- The English text in code and data is the key. `data/i18n/de/*.json` maps each English text to German: one generated file per table in `tools/i18n/de_*.py` (edit the table, run `python3 tools/i18n/build.py`; never edit the json by hand). Separate files keep parallel branches from colliding in one big generated file.
- Keys with `%s` or `%d` are patterns. For example, "%s took %d damage." also translates "Kindlop took 12 damage.", and the values are carried over. Use `{0}`, `{1}` in the German text when the order of the values changes.
- Values that are known texts are translated too, such as item and status names inside a sentence.
- `scripts/core/PatternTranslation.gd` is installed with Godot's TranslationServer. Every Label and Button follows the language with no extra code. Text boxes and custom-drawn text call `Loc.t()`.
- Spirling names, move names, place names and element names stay the same in every language.
- Text addresses the player without gendered words.

## Adding or changing text

1. Write the English text in code or data as usual.
2. Run `python3 tools/i18n_extract.py de`. It prints every player-facing text that has no German yet.
3. Add the German to the matching table in `tools/i18n/` (`de_world.py`, `de_data.py` or `de_ui.py`), then run `python3 tools/i18n/build.py`.

CI runs `python3 tools/i18n_extract.py de --check`, and `tests/unit/test_i18n.gd` checks dialogue, items, the Spirlog, goals, map names, battle messages and that the pixel font has every glyph.

## The other twelve languages

German is the reference: its tables list every English key the game translates. The other languages are kept by hand in `data/i18n/<code>/<table>.json`, one file per German table with the same keys (format `{"_comment", "strings"}`).

- `python3 tools/i18n/check_lang.py` checks placeholders in every language (CI runs it) and reports how many texts each language still lacks. Missing texts only warn, because new German texts arrive every day; they show in English until translated.
- `python3 tools/i18n/check_lang.py fr --json` prints the missing keys of one language with the German as a hint, ready to translate and merge into the matching table.
- Translations follow the same rules as German: names stay English, Chimora's own glossary words (Ring, Vigor, Wayfarer, Art, Unfurl...), no words of the genre's editions in that language, neutral shop texts, the player is addressed without gendered words.
- A new language needs its folder, an entry in `Loc.LANGUAGES` and `Loc.LANGUAGE_NAMES`, and the code in `tools/i18n/check_lang.py`.

## Fonts

- Latin letters with accents and Cyrillic are our own 5x9 pixel glyphs in `scripts/ui/PixelFontExtra.gd`, generated by `tools/fonts/gen_extra_glyphs.py` (accents composed on the base letters, Cyrillic drawn by hand).
- Japanese, Korean and Chinese use `art/fonts/chimora_cjk_8px_<code>.otf`: subsets of Fusion Pixel Font 8px (SIL Open Font License 1.1, `art/fonts/OFL.txt`, renamed as the licence asks), added as fallbacks of the pixel font with the current language first, so shared characters get the regional form. Only the characters the translations use are kept: after a CJK translation adds characters, run `tools/fonts/build_cjk.py` (see its header for the source package). `tests/unit/test_i18n_languages.gd` fails when a letter has no glyph.

## Fitting the screen

Menu rows have 115 pixels for text (`tests/unit/test_ux_text.gd` measures every fixed row in every language with the pixel font; a CJK character is 8 pixels wide). When a German text is too long, shorten it and let the explanation line under the list say the rest.

## Plural forms

Use `Loc.plural(n, "%d coin", "%d coins")`. Both English forms are keys of their own, so German can say "1 Münze" and "3 Münzen".

## Language changes

`Loc.events.language_changed` fires when the language really changes. Text drawn by hand (title status, info texts, toasts, list hints) listens and draws itself again; Labels and Buttons follow by themselves.
