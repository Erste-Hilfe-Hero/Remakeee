# Chimora 1.2.0

Store version after the live 1.1.0 (`3799034`, PR #324). Range: `3799034..33c02b51` on
`claude/project-thread-lhphga-c`: 121 first-parent commits = 115 merged PRs (one of them this release
prep, #447) + 5 direct commits + 1 merge commit.

Version: `python3 tools/bump_version.py --name 1.2.0` -> version name 1.2.0, version code 2 in every
Android and iOS preset and `Online.CLIENT_VERSION` (the lifekit store build adds its own build number).

## Where the texts are

| What | Where | Limit |
| --- | --- | --- |
| Google Play "What's new", 14 languages | `store/android/<lang>/changelogs/default.txt` | 500 |
| App Store release notes (full patch notes), 14 languages | `store/ios/metadata/<lang>/release_notes.txt` | 4000 |
| In-game "What's new" entry, 14 languages | `data/live_content.json` (bundled) and `live/content.json` (version 3, `requires` 1.2.0) | - |

`release_check.py` checks the limits. `live/content.json` carries `requires: "1.2.0"`, so a 1.1.0 game
ignores the patch and does not show 1.2.0 news before the update is out. `latest` stays 1.1.0: raise it
(and only later `min_client`) once 1.2.0 is live in each store (docs/LIVE_CONTENT.md).

## Before the store build

1. `python3 tools/release_check.py --strict` (open item: own domain for `LegalInfo.SITE`).
2. Set `CHIMORA_REF` in lifekit to the merged commit (docs/RELEASE.md).
3. If the Quillmarch link below lands before the build, add Quillmarch, Halcyra and Quivermoor to the texts.
4. After 1.2.0 is live: publish `live/content.json` with the `Live content` workflow and raise `latest`.
